# Seven Minute Workout

A personal 7-minute workout app in a single web page: 12 classic moves, animated demos, voice and beep cues, and a calendar of past workouts.

- **Run it:** open the GitHub Pages address for this repository. On a phone, use "Add to Home Screen" to install it; it then works offline.
- **Your data:** workout history is stored only on your device. Use Export / Import on the History tab to back it up or move it.
- **Settings:** work and rest times, rounds, voice and beeps are under Setup.

Files: `index.html` (the whole app), `sw.js` (offline cache), `manifest.webmanifest` and icons (home-screen install).
